# PWA FullCover

起因是每次在手机上启动酒馆都要输密码，我感觉麻烦，给密码关了后每次都有一个雷霆大缝，原本的有小缝还能忍受，关了之后输入栏底下那一栏空的直接就给我看死了，这插件适用于同样在safari把酒馆添加到主屏幕上想要得到原生app质感的。

⚠️ **只适配 iOS Safari 的"添加到主屏幕"**。PC、安卓目前没有发现兼容性问题，装上默认开启，扩展面板里有开关。

第一种安装方法：扩展面板 → Install extension，填

```
https://github.com/atostar409/st-pwa-fullcover
```

第二种：直接用仓库里的 `setup-mobile.bat` 丢到酒馆的根目录，就是有 Start.bat 这个脚本的文件页。

注意：

- 第一次打开会灰屏卡个半分钟一分钟，是正常的，别急。
- 使用脚本会一键关掉酒馆的密码认证、同个wifi下如果别人想看你的色色记录也可以登录了嘻嘻，在公共网络环境下斟酌使用。
- 是在 SillyTavern 1.17 的环境里写的，不确保其他版本可以用，但应该不会出大问题。有问题开扩展里的"显示调试信息"，把红条数字截图甩我
